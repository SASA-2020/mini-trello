# 📝 سامانه مدیریت پروژه و وظایف (مینی ترلو)

---

## 🚀 معرفی پروژه

این پروژه یک پلتفرم تحت وب مینیمال برای مدیریت وظایف و پروژه‌های تیمی است که با هدف جلوگیری از تداخل وظایف و ایجاد شفافیت در توزیع کارها توسعه یافته است. در این سامانه، کاربران می‌توانند پروژه‌های مختلف را تعریف کرده، تسک‌ها را ایجاد و با تعیین مسئول، اولویت و سررسید، آن‌ها را در بوردها مدیریت کنند.

## 🛠 تکنولوژی‌های استفاده شده

- **فرانت‌اند:** React, Next.js (App Router), Tailwind CSS
- **بک‌اند:** Next.js Server Actions
- **پایگاه داده:** PostgreSQL
- **ORM:** Prisma

---

## 📦 مراحل نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها

```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی

یک فایل `.env` در کنار فایل `package.json` ایجاد کرده و مقدار زیر را در آن قرار دهید:

```env
DATABASE_URL="postgresql://USERNAME:PASSWORD@localhost:5432/minitrello_db?schema=public"
```

> **نکته:** به جای `USERNAME` و `PASSWORD`، نام کاربری و رمز عبور PostgreSQL خود را وارد کنید.

### ۳. آماده‌سازی پایگاه داده

```bash
npx prisma generate
npx prisma migrate dev
```

### ۴. اجرای پروژه

```bash
npm run dev
```

اکنون می‌توانید مرورگر خود را باز کرده و آدرس `http://localhost:3000` را جستجو کنید تا وارد محیط سامانه شوید.
